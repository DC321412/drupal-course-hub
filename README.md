# Course Hub (Drupal 11)

## Setup
1. composer install
2. Drupal install karo, phir: vendor/bin/drush cim -y
3. Sample content ke liye db/course-site.sql import karo
4. php -S localhost:8888 -t web web/.ht.router.php

## Includes
- Course content type (Title, Description, Image, Category)
- Course Category taxonomy aur sample courses
- /courses Views page, main menu, site settings
